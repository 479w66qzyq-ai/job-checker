# job-checker

Личный некоммерческий инструмент для поиска работы. Используется одним человеком — автором репозитория.

## Что делает

Периодически запрашивает вакансии по заданным поисковым запросам через официальные API
работных сайтов, сравнивает их с резюме автора и присылает подходящие в личный Telegram
вместе с оценкой соответствия.

## Что не делает

- Не публикует и не перепродаёт полученные данные
- Не передаёт данные третьим лицам
- Не имеет публичного доступа и не работает как сервис для других пользователей
- Не отправляет отклики автоматически — письма только готовятся, отправляет человек вручную

## Источники данных

Официальные API работных сайтов, в рамках правил использования каждого из них.
